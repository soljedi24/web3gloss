web3 Glossary App

This project is a simple yet comprehensive Crypto Glossary application designed to help beginners learn and understand Web3 and blockchain-related terms. The app provides clear definitions for key cryptocurrency concepts, enabling users to track their progress and expand their knowledge of Web3 technologies.

Features
100+ Web3 terms: Definitions for key blockchain, cryptocurrency, and Web3 terms.

Search functionality: Easily find terms by searching for keywords.

"Learned" toggle: Mark terms as learned to track progress.

Lightweight: No external frameworks, works with vanilla HTML, CSS, and JavaScript.
